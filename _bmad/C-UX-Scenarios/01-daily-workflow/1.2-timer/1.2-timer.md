## Overview

**Page Purpose:** 按番茄钟专注执行当前任务，沉浸式工作，不被打断焦虑困扰。被打断时一键记录，AI 自动处理后续安排。

**Entry Points:**
- 从 Dashboard 点击"开始第一个番茄钟"进入（主要入口）
- 侧边导航 Timer 进入（手动开始）
- 从 Schedule 确认日程后进入

**User Mental State:**
- **触发:** 从 Dashboard 确认日程 OK，准备开始执行
- **希望:** 这 25 分钟能专注搞定一个任务，不被任何事打断
- **恐惧:** 刚开始就被拉去开会/同事呼叫，回来忘了进度

**Main User Goal:** 专注完成当前番茄钟，被打断后不用自己操心后续安排

**Business Goal:** 番茄钟完成率提升，用户对 AI 打断处理产生信任

**Exit Action:** 任务超时或被打断 → AI 弹窗"后续安排已调整"→ 点击进入 Schedule（01.3）

## Layout Sections

### 1. 当前任务信息栏 (primary)
- 任务名称 + 所属象限标签
- 预估番茄钟数 / 当前第几个

### 2. 番茄钟计时器 (primary)
- 圆环倒计时（现有 TimerDisplay ✅）
- 暂停/继续/提前完成按钮

### 3. 打断处理 (primary)
- "记录打断"按钮 — onClick → 弹出打断原因选择（会议/同事呼叫/紧急事务/其他）→ AI 自动重排后续日程
- 打断后提示："已记录，AI 正在调整后续安排..."

### 4. 控件栏 (secondary)
- 暂停/继续/跳过休息（现有 TimerControls ✅）

### 5. 最近记录 (secondary)
- 今日番茄钟完成列表（现有 ✅）

| `timer-sessions` | 最近记录列表 | ✅ 已有 |

## Key States

- **Running:** 计时中，绿色圆环动画，"记录打断"按钮可用
- **Paused:** 暂停，橙色圆环
- **Interrupted:** 打断后，灰色圆环 + "AI 正在调整后续安排..." loading
- **Completed:** 番茄钟完成，弹窗"完成！休息 5 分钟或开始下一个"

## Interaction Behaviors

- `timer-display` click → 开始/暂停计时
- `timer-interrupt` click → 弹出打断原因选择 → AI 重排 → 跳转 Schedule
- 番茄钟结束 → 自动标记任务完成 + 振动/铃声提醒
