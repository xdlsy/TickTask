# TickTask - 产品概念

## 核心结构性创意

TickTask 本质上是一个**由 AI 驱动的自动排程引擎**，形成持续优化的效率闭环：

```
录入任务 → AI 分析&排程 → 番茄钟粒度日程 → 动态调整 → 效率分析 → 反哺排程
```

## 结构原则

**AI 是核心决策者，不是附加功能。** 规则算法只作为 AI 不可用时的降级方案。

## 为什么这个结构？

| 传统方式 | TickTask 方式 |
|----------|---------------|
| 人脑规划优先级 | AI 分析任务重要性和紧急度 |
| 手动排日历 | AI 按番茄钟粒度生成日程 |
| 打断后自己重新安排 | AI 自动重排剩余计划 |
| 凭感觉评估效率 | AI 分析数据给出改进建议 |

## 具体场景

1. 用户早上录入或回顾任务
2. AI 根据任务属性、历史数据、当前时间窗口，生成 09:00-18:00 的番茄钟粒度日程
3. 用户跟着执行，番茄钟计时
4. 如果中途被打断或某任务超时，AI 自动调整后续安排
5. 如有任务无法当天完成，AI 主动提醒并建议何时处理
6. 收工时，AI 总结当天效率数据
7. 第二天排程时，AI 参考历史数据优化排列

## 源自概念的核心功能

- 智能任务分类（AI 判断重要性/紧急度 → 象限）
- 自动日程生成（AI 排时间块）
- 动态重排（打断/超时触发）
- 延迟提醒+建议（AI 判断风险和替代方案）
- 效率分析仪表盘（AI 提炼趋势和建议）
