# TickTask - 目标用户画像

## 主要用户：软件开发团队成员（含 Project Leader）

### 日常现状
- 早上到公司，**脑子里过一遍**紧急事项，直接开干
- 没有使用任何任务管理工具（Notion/Todoist/Trello等）
- 最多"有个简单记录的地方"

### 核心失败模式（四大痛点）

| 失败模式 | 表现 | 后果 |
|----------|------|------|
| **打断** | 被拉去开会/处理紧急事 | 回头忘记原进度，上下文丢失 |
| **琐事优先** | 整天忙小事 | 重要的事没推进 |
| **决策瘫痪** | 事情太多不知从何开始 | 拖延，或反复切换任务 |
| **规划成本** | 自己排计划费时费力 | 规划本身成为消耗 |

### 核心使用方式
1. 把任务录入 TickTask
2. 工具自动生成番茄钟粒度的日计划
3. 跟着执行，无需费心规划
4. 遇到打断/延期，工具自动调整

### 目标感受
轻松 —— "终于有工具帮我安排了"，"不用费心思规划，跟着做就行"

### 团队适用性
- 不论个人偏好"提前规划"还是"救火队员"，统一使用：录入 → 自动排程 → 跟着执行
- 用户本人（Project Leader）先验证，再推广至 ~30 人团队
