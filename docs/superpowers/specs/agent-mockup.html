TickTask Agent 入口 — 设计 Mockup

下面用 6 个场景 演示 Agent 抽屉的视觉与交互。抽屉宽 480px，从右侧滑入，叠在当前页（这里是 Tasks 页）之上。
  • PermRead 读类工具：自主执行（绿色边）
  • PermWrite 写类工具：需用户在卡片上点"确认"（黄色边）
  • PermDangerous 危险操作：inline 红色卡片 + 弹窗二次确认（红色边）
  • 消息流支持流式 LLM 输出（typing indicator）、tool_call 卡片嵌套、tool_result 回显
