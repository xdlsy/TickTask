# TickTask Frontend

Vue 3 前端应用，提供时间管理功能的用户界面。

## 开发

```bash
# 安装依赖
npm install

# 运行开发服务器
npm run dev

# 构建
npm run build

# 预览构建结果
npm run preview
```

## 技术栈

- Vue 3 + TypeScript
- Element Plus UI 组件库
- Pinia 状态管理
- Vue Router 路由
- Axios HTTP 客户端
- Vite 构建工具

## 功能

- 仪表盘：查看今日统计和快速操作
- 番茄时钟：专注计时器和休息计时
- 任务管理：四象限视图任务管理
- 数据分析：统计数据和趋势图表
